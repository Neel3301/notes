# Plan: Phase 8 — Bi-directional Linking (`[[Note Title]]`) & Export

## Overview
Implement bi-directional note linking (`[[Note Title]]`) with linked references discovery, and full note export capabilities (Markdown download with frontmatter and full JSON vault backup/restore).

---

## Requirements Addressed
- **DATA-03**: User can export individual notes as Markdown files or download a full JSON backup.
- **ORG-03**: User can write `[[Note Title]]` backlinks that auto-link to corresponding notes and display connected references.

---

## Tasks

### Task 1: Add Backlinks Indexer to `notesStore`
- In `src/data/notesStore.js`:
  - Implement `getBacklinks(noteIdOrTitle)`:
    - Finds all other active notes whose content or block content references `[[Target Title]]`.
    - Returns array of `{ sourceNote, snippet }`.

### Task 2: Build Backlinks Drawer / Component
- Create `src/components/note/BacklinksDrawer.jsx`:
  - Renders linked references with note title, notebook, and contextual text snippet.
  - Clicking any linked reference smoothly navigates to that note.
  - Provides quick link suggester in edit mode to insert `[[Other Note]]`.

### Task 3: Build Export & Backup System
- In `CourseDetailScreen.jsx`:
  - Add export menu:
    - "Export as Markdown (.md)": triggers browser file download of formatted markdown with frontmatter.
    - "Export as JSON (.json)": downloads raw note JSON.
- In `MenuScreen.jsx`:
  - Add "Download Vault Backup" (`.json` export).
  - Add "Restore Vault Backup" (JSON file reader calling `notesStore.importFromJson`).

### Task 4: Automated Verification
- Create `src/data/verify-backlinks-export.js`:
  - Validate backlink detection across note bodies and blocks.
  - Validate Markdown download string generator.
  - Validate vault backup export and import cycle.
  - Execute test suite and verify 100% assertions pass.
