# Plan: Phase 9 — AI Assistant Action Sheet

## Overview
Implement an integrated AI Assistant action drawer within the mobile note editor. Users can trigger 1-tap assistant intelligence: Summarize Note, Extract Action Items into interactive checklists, Auto-generate Tags, and Expand / Rephrase note ideas, with instant application to note content and blocks.

---

## Requirements Addressed
- **AI-01**: Built-in AI action drawer provides 1-tap assistance (Summarize, Extract Action Items, Auto-generate Tags, Rephrase).

---

## Tasks

### Task 1: Create AI Assistant Engine
- Build `src/services/aiAssistantService.js`:
  - `summarizeNote(note)`: Generates concise executive summary and key points.
  - `extractActionItems(note)`: Synthesizes actionable checklist tasks.
  - `generateTags(note)`: Proposes high-relevance tags.
  - `expandOrPolish(note)`: Polishes structure, headings, and grammar.

### Task 2: Build AI Assistant Action Sheet Component
- Create `src/components/note/AiAssistantSheet.jsx`:
  - Slide-up bottom sheet with dark minimalist backdrop and cream accent highlights.
  - Sparkles icon trigger and quick action cards:
    - "Summarize"
    - "Extract Tasks"
    - "Generate Tags"
    - "Polish & Expand"
  - Real-time preview with 1-tap "Apply to Note" / "Insert as Block" buttons.

### Task 3: Integrate into Note Detail Screen
- In `CourseDetailScreen.jsx`:
  - Add `Sparkles` AI Assistant button in header toolbar.
  - Wire actions: appending checklist block, attaching tags, appending summary callout.

### Task 4: Automated Verification
- Create `src/data/verify-ai-assistant.js`:
  - Test all 4 AI assistant routines.
  - Test applying AI generated tasks as a new modular checklist block.
  - Test applying auto-generated tags to note.
  - Verify store persistence and state reactivity.
