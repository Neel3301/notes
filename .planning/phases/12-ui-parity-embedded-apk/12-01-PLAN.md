# Plan: Phase 12 — 100% UI Parity Between Web and Android APK

## Overview
Unify the Web and Android APK experience so that the installed mobile APK renders the EXACT same pixel-perfect UI, animations, canvas sketching, audio memos, AI Assistant sheet, and dark aesthetics as the Web application.

---

## Tasks

### Task 1: Prepare Web App for Offline & Embedded Execution (PRT-01)
- Configure `web/vite.config.js` with `base: './'` for relative asset resolution.
- Update `web/src/App.jsx` to use `HashRouter` for zero-server offline navigation.
- Verify `web/` builds with `npx vite build` into `web/dist/`.

### Task 2: Embed Web Bundle into Native Android Project (PRT-02)
- Ensure native assets directory `mobile/android/app/src/main/assets/web/` exists.
- Copy all built files from `web/dist/` into `mobile/android/app/src/main/assets/web/`.
- Ensure `react-native-webview` is configured in `mobile/App.js` with full file and DOM storage permissions, edge-to-edge black screen, and hardware acceleration.

### Task 3: Build Unified Android Release APK (PRT-03)
- Map workspace to short root drive `M:`.
- Compile release APK with `.\gradlew.bat assembleRelease`.
- Copy output artifact to `apk/edsy-notes.apk`.

### Task 4: Automated Parity Verification
- Create test suite `mobile/verify-parity.js`.
- Verify Web build, embedded Android assets, React Native WebView wrapper, and standalone `.apk`.
- Generate `12-01-SUMMARY.md` and `12-VERIFICATION.md`.
