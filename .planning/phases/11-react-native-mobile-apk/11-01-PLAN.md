# Plan: Phase 11 — React Native Mobile App & Android APK Build

## Overview
Build a native React Native (Expo) mobile application inside `/mobile` on branch `react-native-mobile`, preserving the existing web app in `/web`, and compile a standalone, installable Android `.apk` file ready to install on physical mobile devices.

---

## Tasks

### Task 1: Restructure Workspace into `/web` and `/mobile` (MBL-01)
- Create `web/` directory.
- Preserve existing web app code and configuration in `web/`.
- Verify that `web/` builds cleanly.

### Task 2: Scaffold React Native App in `/mobile` (MBL-02)
- Initialize Expo / React Native project inside `mobile/`.
- Configure package name `com.edsy.notesapp` and app metadata in `app.json`.
- Install native dependencies:
  - `@react-navigation/native`, `@react-navigation/native-stack`
  - `react-native-screens`, `react-native-safe-area-context`
  - `lucide-react-native`, `react-native-svg`
  - `@react-native-async-storage/async-storage`

### Task 3: Build React Native Mobile Screens & Components (MBL-02)
- Create `mobile/src/theme/tokens.js` (Color, typography, radius tokens).
- Create `mobile/src/data/notesStore.js` (AsyncStorage-backed reactive note store).
- Implement Core Components:
  - `NoteCard`: signature card with blue/light/yellow variants, author, title, heart toggle.
  - `AppHeader`: logo `.edsy`, left icon (menu, back, close).
  - `DatePager`: horizontal date strip (`Mon. 12` ... `Tue. 13`).
  - `SearchPill`: outlined dark search input.
- Implement Screens:
  - `TimelineScreen`: horizontal scroll card carousel and date pager.
  - `NotesCatalogScreen`: search input, tag filter pills, stacked note cards.
  - `NoteEditorScreen`: title, markdown body, modular blocks, backlinks.
  - `MenuScreen`: typographic menu with dynamic counts and sub-views.

### Task 4: Native Android Prebuild & Gradle APK Compilation (MBL-03)
- Run `npx expo prebuild --platform android` to generate native `android/` project and Gradle wrapper.
- Configure Android SDK environment variables (`ANDROID_HOME`, `JAVA_HOME`).
- Run `./gradlew assembleDebug` or `assembleRelease` inside `mobile/android`.
- Copy compiled `.apk` to root `apk/edsy-notes.apk` for 1-tap download and installation.

### Task 5: Verification & Documentation
- Automated script `src/data/verify-mobile-apk.js` or `mobile/verify-mobile.js`.
- Test web app build in `web/` and verify `.apk` binary file size and validity.
- Create `11-01-SUMMARY.md` and `11-VERIFICATION.md`.
