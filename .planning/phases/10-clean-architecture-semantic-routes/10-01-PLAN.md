# Plan: Phase 10 — Clean Architecture & Semantic Route Alignment

## Overview
Refactor all screen filenames, component locations, routes, and data naming from the legacy dummy course template into clean, intuitive mobile note app architecture.

---

## Tasks

### Task 1: Component Migration & Course Directory Cleanup
- Move `src/components/course/CourseCard.jsx` to `src/components/note/NoteCard.jsx`.
- Update internal component name to `NoteCard`.
- Delete `src/components/course/` directory.

### Task 2: Data & Content Vocabulary Alignment
- In `src/data/content.js`:
  - Rename exports:
    - `studyPlanningData` -> `timelineData` (with backward compat alias)
    - `courseOverviewData` -> `notesCatalogData` (with backward compat alias)
    - `courseDetailData` -> `noteEditorData` (with backward compat alias)
  - Clean up any stale course references.

### Task 3: Screen Renaming
- Rename `src/screens/StudyPlanningScreen.jsx` -> `src/screens/TimelineScreen.jsx`.
- Rename `src/screens/CourseOverviewScreen.jsx` -> `src/screens/NotesCatalogScreen.jsx`.
- Rename `src/screens/CourseDetailScreen.jsx` -> `src/screens/NoteEditorScreen.jsx`.
- Update component names and imports inside each screen file.

### Task 4: App Route Wiring & Backwards-Compatible Redirects
- In `src/App.jsx`:
  - Import `TimelineScreen`, `NotesCatalogScreen`, and `NoteEditorScreen`.
  - Wire clean routes:
    - `/` -> redirects to `/timeline`
    - `/timeline` -> `<TimelineScreen />`
    - `/notes` -> `<NotesCatalogScreen />`
    - `/editor` and `/note/:id` -> `<NoteEditorScreen />`
    - `/menu` -> `<MenuScreen />`
  - Add backwards-compatible redirect routes:
    - `/study-planning` -> `<Navigate to="/timeline" replace />`
    - `/course-overview` -> `<Navigate to="/notes" replace />`
    - `/course-detail` -> `<Navigate to="/editor" replace />`
- Update internal navigation calls in `MenuScreen.jsx`, `TimelineScreen.jsx`, `NotesCatalogScreen.jsx`, and `NoteEditorScreen.jsx`.

### Task 5: Automated Verification
- Create `src/data/verify-architecture.js` to assert:
  - All new screens exist and export correctly.
  - New route mappings and components resolve.
  - Legacy `src/components/course/` is completely purged.
- Run all test suites and ensure 100% passing tests.
- Rebuild production bundle with `npm run build`.
