# Plan: Phase 6 — Canvas Freehand Sketch Pad & Audio Memo Player

## Overview
Implement the HTML5 Canvas freehand sketchpad and the Audio Memo recorder/player within the Edsy mobile note editor. Users can draw sketches with custom stroke widths and color swatches matching the app's palette, save drawings to note schema, and record/play audio voice memos with animated waveform and scrubbable progress bar.

---

## Requirements Addressed
- **NOTE-04**: User can switch to the Canvas tab to draw/sketch freehand doodles with stroke controls and save them into the note.
- **NOTE-05**: User can record and playback audio memos with progress bar and timestamp indicator.

---

## Tasks

### Task 1: Create Canvas Sketchpad Component
- Create `src/components/note/CanvasSketchpad.jsx`:
  - Responsive HTML5 `<canvas>` with DPR scaling for retina mobile clarity.
  - Pen, Eraser, and stroke width toggles (Fine: 2px, Medium: 5px, Bold: 10px).
  - Palette swatches: Cream (`#E5E7DA`), Blue (`#6F91B6`), Yellow (`#CABC3F`), White (`#FFFFFF`).
  - Action buttons: Undo stroke, Clear canvas, Save sketch.
  - Pointer events (`pointerdown`, `pointermove`, `pointerup`) with `touch-action: none` for smooth touch/mouse drawing.
  - Automatically loads and renders `initialData` (data URL) on mount.

### Task 2: Create Audio Memo Player & Recorder Component
- Create `src/components/note/AudioMemoBlock.jsx`:
  - Audio card with dark minimalist theme, play/pause toggle button, animated waveform bars, and scrubbable progress bar.
  - Elapsed and total duration time indicators (`mm:ss`).
  - Playback speed switcher (`1.0x`, `1.5x`, `2.0x`).
  - "Record Memo" feature: live recording timer, pulsing recording badge, microphone capture / simulated recording audio generator that saves duration, label, and timestamp to `note.audioData`.

### Task 3: Integrate with Note Detail & Note Store
- Update `src/screens/CourseDetailScreen.jsx`:
  - In "Canvas" tab: mount `<CanvasSketchpad>` connected to `note.sketchData` with auto-save.
  - In "Preview" tab: display saved canvas sketch preview thumbnail/card and audio memo block if present.
  - Add quick action to attach audio memo or launch canvas sketch.

### Task 4: Automated Verification
- Create `src/data/verify-canvas-audio.js`:
  - Validate sketch saving, data URL storage, and clearing.
  - Validate audio memo attachment, duration calculation, and audio playback state progression.
  - Execute test suite and verify all assertions pass.
