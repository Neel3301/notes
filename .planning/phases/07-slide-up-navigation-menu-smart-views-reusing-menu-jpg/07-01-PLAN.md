# Plan: Phase 7 — Slide-up Navigation Menu & Smart Views (Reusing menu.jpg)

## Overview
Adapt the full-screen slide-up `menu.jpg` into an advanced navigation and organization center. The menu features giant `.text-menu` typography (38px font-light), dynamic counts for Notebooks, Tags, Favorites, and Trash. Users can organize notes into notebooks, filter by tags, and manage the Trash with full restore and permanent purge capabilities.

---

## Requirements Addressed
- **ORG-01**: Full-screen slide-up menu adapts `/menu` with giant `.text-menu` typography for Notebooks, Tags, Pinned, Archive, and Trash.
- **ORG-02**: User can organize notes into notebooks/folders and assign custom tags.
- **ORG-04**: User can pin important notes to top and send unwanted notes to Trash with restore/permanent delete.

---

## Tasks

### Task 1: Enhance MenuScreen with Smart Views
- Update `src/screens/MenuScreen.jsx`:
  - Giant `.text-menu` items: "Timeline", "All Notes", "Notebooks", "Tags", "Favorites", "Trash".
  - Live count indicators for each section.
  - Sub-views for "Notebooks", "Tags", and "Trash" with smooth back transitions.

### Task 2: Implement Trash Management View
