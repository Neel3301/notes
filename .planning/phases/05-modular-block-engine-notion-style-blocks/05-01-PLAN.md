# Plan: Phase 5 — Modular Block Engine (Notion-style Blocks)

## Overview
Implement the Modular Block Engine for notes adhering to the `course-detail.jpg` numbered lesson row layout (`01`, `02`, `03`...). Users can organize notes into modular blocks (Text, Interactive Checklist, Callout, Code), toggle checklist tasks, reorder blocks, add new blocks, and delete blocks with instantaneous persistence to `notesStore`.

---

## Requirements Addressed
- **NOTE-03**: User can structure notes with modular blocks (text, interactive checklist items, callout boxes).

---

## Tasks

### Task 1: Create Modular Block Components
- Build `src/components/note/BlockItem.jsx`:
  - Numbered indicator (`01`, `02`, `03`...) matching `course-detail.jpg`.
  - Type badge (`Text`, `Checklist`, `Callout`, `Code`).
  - Interactive expand/collapse toggle (`ChevronDown` / `ChevronUp`).
  - Type-specific rendering:
    - `text`: Editable textarea (edit mode) or `MarkdownRenderer` (preview mode).
    - `checklist`: Interactive tasks with checkboxes; toggling `done` works in preview and edit mode. Edit mode supports adding and removing checklist items.
    - `callout`: Sleek dark-mode highlight box (`bg-[#151515] border-l-2 border-[#E5E7DA]`) with icon and quote.
    - `code`: Monospace syntax block with language tag.
  - Controls: Move Up, Move Down, Delete block.

### Task 2: Create Block List & Add Block Toolbar
- Build `src/components/note/BlockList.jsx`:
  - Renders list of `BlockItem`s.
  - "+ Add block" trigger with segmented type chooser (`Text`, `Checklist`, `Callout`, `Code`).
  - Dispatches updates through `onChange(updatedBlocks)`.

### Task 3: Integrate with Note Detail Screen & Auto-Save
- Update `src/screens/CourseDetailScreen.jsx`:
  - Replace static accordions with `BlockList`.
  - Hook into `notesStore.updateNote(note.id, { blocks })`.
  - Ensure checklist toggle immediately saves to `notesStore` without requiring "Edit" mode toggle.

### Task 4: Automated Verification
- Create `src/data/verify-blocks.js`:
  - Verifies block schema, type integrity, checklist toggle, add, delete, and reorder.
  - Run node test script and verify all assertions pass.
