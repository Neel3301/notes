# Workflow: gsd

Get Shit Done (GSD) creates hierarchical project plans optimized for solo agentic development.

## Core Commands:
- `/gsd-new-project` - Initialize new project (interview, requirements, roadmap)
- `/gsd-plan-phase <N>` - Create detailed plan for a phase
- `/gsd-execute-phase <N>` - Execute a phase with wave-based execution
- `/gsd-progress` - Check project progress and determine next actions
- `/gsd-quick` - Execute a quick task with atomic tracking
- `/gsd-help` - Show complete GSD command reference
- `/gsd-stats` - Display project statistics
